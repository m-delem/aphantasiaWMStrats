# WM-FTT: task design and history

**See the vignette.** `vignettes/articles/task-design.Rmd` covers the
paradigm, the trial structure, the version history and the defects each
version exposed. It is the account, and it is more complete than anything
that would be written here.

This file exists to hold the number in the sequence and to record the one
thing the modelling docs depend on: **the task pays points per feature and
recall of each feature is optional**, so declining to report is an
allocation decision rather than missing data. That premise is what
`04-response-propensity.md` and `09-joint-model.md` rest on.
