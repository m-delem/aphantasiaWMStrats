# WM-FTT: questionnaire psychometrics

**Status: stub, created 2026-08-24 during the restructure.** Distinct from
`06-task-validity.md`, which concerns the reliability and validity of the
*task*. This doc concerns the *instruments*: VVIQ, OSIVQ, NIEQ, TAS-20.
Findings exist and are scattered; none has a home.

## Findings that need collecting here

- **VVIQ/OSIVQ multitrait-multimethod pattern test fails.** Recorded but
  not written up. The implication for using OSIVQ subscales as predictors
  needs stating.
- **NIEQ pair-consistency for sensory focus falls below threshold (0.49).**
  Sensory awareness was already identified as the weakest dimension in the
  published validation, so this is a replication of a known weakness
  rather than a surprise, but it constrains which NIEQ dimensions can
  carry weight. Unsymbolised thinking is the dimension of substantive
  interest, hypothesised higher in aphantasics.
- **OSIVQ reverse-keying is inconsistent across versions**: v1 and v2 hold
  unreversed values in the raw item columns, v3 holds reversed ones.
  Documented; downstream implications still need tracking.

## Why this is separate from task validity

They answer different questions. `06` asks whether the WM-FTT measures
anything stable. This doc asks whether the questionnaires do, and both
have to hold before any association between them means anything.

## Relationship to the exploratory strand

`12-scale-structure.md` analyses relationships *between* scales. This doc
establishes whether each scale is worth analysing at all, so it comes
first.
